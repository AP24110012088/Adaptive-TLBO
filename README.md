# Adaptive TLBO Framework with Dynamic Priority Adjustment and Faculty Satisfaction Prediction for Academic Timetable Scheduling

## Overview

This project presents an **Adaptive Teaching-Learning-Based Optimization (Adaptive TLBO)** framework for solving the Academic Timetable Scheduling Problem (ATSP). The proposed approach enhances the conventional TLBO algorithm by integrating adaptive optimization strategies, dynamic priority adjustment, faculty satisfaction evaluation, elite preservation, adaptive mutation, local timetable refinement, and diversity refresh mechanisms to generate high-quality conflict-free academic timetables.

The framework is implemented in **Python** and produces optimized university timetables along with comprehensive performance reports, statistical analyses, and visualizations.
